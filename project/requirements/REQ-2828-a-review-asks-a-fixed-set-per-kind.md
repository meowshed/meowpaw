# REQ-2828

**Withdrawn by ADR-2300. Replaced by REQ-3624.**

It read: a review of a record artifact MUST work through a fixed set of questions for that kind.

Most defects here are omissions, and an omission is invisible in a difference.

ADR-2300 closes a requirement with the tasks that name it and keeps no verification step, evidence file or record review, and REQ-3624 states what holds in its place.
