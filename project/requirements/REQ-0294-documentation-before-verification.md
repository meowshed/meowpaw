# REQ-0294

**Withdrawn by ADR-2300. Replaced by REQ-3618.**

It read: documentation MUST be produced before verification, so that verification covers it and review sees it verified.

Documentation no check saw is the artifact most likely to be wrong and least
likely to be caught.

ADR-2300 closes a requirement with the tasks that name it and keeps no verification step, evidence file or record review, and REQ-3618 states what holds in its place.
