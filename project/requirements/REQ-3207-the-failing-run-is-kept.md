# REQ-3207

**Withdrawn by ADR-2300. Replaced by REQ-3642.**

It read: the run in which the cover step's checks fail MUST be kept as the cover step's evidence.

Without it, nobody can tell afterwards whether a check ever failed.

ADR-2300 closes a requirement with the tasks that name it and keeps no verification step, evidence file or record review, and REQ-3642 states what holds in its place.
