# REQ-0301

A task MUST carry two completion tests: its acceptance criteria, which say
what this task makes true, and the repository's definition of done, which says
what any finished task satisfies.

They answer different questions and are owned by different parties, so
collapsing them into one name produces a condition that is either restated
everywhere or checked nowhere.
