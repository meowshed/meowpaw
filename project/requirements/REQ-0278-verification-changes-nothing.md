# REQ-0278

**Withdrawn by ADR-2300. Replaced by REQ-3606.**

It read: verification MUST NOT modify code, requirements or the specification.

It reports, and a person decides which side is wrong. A step that both detects
and resolves divergence will resolve it by rewording the requirement.

ADR-2300 closes a requirement with the tasks that name it and keeps no verification step, evidence file or record review, and REQ-3606 states what holds in its place.
