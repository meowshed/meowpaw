# REQ-3112

Onboarding MUST recover as a draft decision each choice that a document, an
issue or a pull request records together with the alternative it rejected,
citing the discussion.

A pull request discussion that weighs options and merges one is the only
place a rejected alternative survives, because code shows only the winner.
