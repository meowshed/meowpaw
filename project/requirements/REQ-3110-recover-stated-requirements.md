# REQ-3110

Onboarding MUST recover as a draft requirement each obligation that the
repository's documents, issues or pull requests state, citing the statement it
came from.

A person wrote the obligation down, so recovering it records what somebody
asked for; code alone states no obligation, and none is recovered from it.
