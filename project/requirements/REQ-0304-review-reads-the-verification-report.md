# REQ-0304

**Withdrawn by ADR-2300. Replaced by REQ-3626.**

It read: review MUST read the verification report, because a review that has not seen the checks spends its attention on what a check would have found.

ADR-2300 closes a requirement with the tasks that name it and keeps no verification step, evidence file or record review, and REQ-3626 states what holds in its place.
