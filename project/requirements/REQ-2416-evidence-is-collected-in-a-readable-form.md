# REQ-2416

Where the ecosystem provides a machine-readable report format for a verb, the
pack MUST collect the result in it, and where none exists the pack MUST say
that the evidence is captured output.

Evidence has to be readable after the terminal has scrolled away, and a reader
must be able to tell a parsed result from a transcript.
