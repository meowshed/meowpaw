# REQ-4000

Where an approved defect directly carries tasks and the repository declares a
tracker, the harness MUST be able to project and check those tasks there with
the same mapping and synchronisation behaviour as tasks an epic carries.

The user's instruction of 2026-10-03 imposed support for defect-authorised
tasks, and RES-0331 establishes that their existing records supply the same
projection inputs.
