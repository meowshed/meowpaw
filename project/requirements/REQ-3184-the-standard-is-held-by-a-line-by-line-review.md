# REQ-3184

The writing standard MUST be held by a line-by-line review of the text by a
model, run before the text is published, and that review MUST report what it
found rather than editing silently.

A pattern reads words and the standard is mostly about shape, so a check over
words passes a document that opens every paragraph in bold and buries its
point. A reader catches that, and a model reading line by line is the only
reader available on every text this harness produces.
