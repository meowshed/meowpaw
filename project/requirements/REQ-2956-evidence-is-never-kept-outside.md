# REQ-2956

**Withdrawn by ADR-2300. Replaced by REQ-3614.**

It read: evidence MUST be kept in the repository however large it is.

Evidence that lives on one machine is an assertion to everyone else.

ADR-2300 closes a requirement with the tasks that name it and keeps no verification step, evidence file or record review, and REQ-3614 states what holds in its place.
