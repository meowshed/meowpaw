# REQ-2370

Unattended approval MUST be a route the harness declares and reports, rather
than a mode it enters, and the route MUST appear in the run's own report like
any other classification.

A person reading the result in the morning has to be able to tell which gates
a person passed from which the harness passed, and that is only possible if
the route was recorded when it was taken.
