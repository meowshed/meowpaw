# REQ-0280

**Withdrawn by ADR-2300. Replaced by REQ-3600.**

It read: a task MUST be verified by whether its evidence closes the requirements it claimed to close.

ADR-2300 closes a requirement with the tasks that name it and keeps no verification step, evidence file or record review, and REQ-3600 states what holds in its place.
