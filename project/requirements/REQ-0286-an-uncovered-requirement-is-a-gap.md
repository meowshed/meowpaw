# REQ-0286

**Withdrawn by ADR-2300. Replaced by REQ-3608.**

It read: where epic verification finds a requirement its authorising record addresses that no task closes, the harness MUST report it as a gap rather than adding a task silently.

ADR-2300 closes a requirement with the tasks that name it and keeps no verification step, evidence file or record review, and REQ-3608 states what holds in its place.
