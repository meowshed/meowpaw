# REQ-0872

**Withdrawn by ADR-2910. Replaced by REQ-3728.**

It read: the completion condition and the budget MUST both be stated before a run starts.

It required the person to state every bound in the command. Defaults let the command name fewer, so REQ-3728 requires the run to state the bounds it runs under, defaults included, before its first iteration.
