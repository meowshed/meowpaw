# REQ-0325

**Withdrawn by ADR-2300. Replaced by REQ-3622.**

It read: a requirement deferred with a reason MUST be revisited when its epic is verified, because that is the only point at which anything looks at it again.

ADR-2300 closes a requirement with the tasks that name it and keeps no verification step, evidence file or record review, and REQ-3622 states what holds in its place.
