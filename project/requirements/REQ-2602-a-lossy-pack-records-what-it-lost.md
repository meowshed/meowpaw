# REQ-2602

Where a pack was produced in a mode that removes content, the harness MUST
record the mode with any finding drawn from it and MUST use such a mode only
for questions about structure.

A conclusion about behaviour cannot come from a pack with the bodies removed,
and where the boundary between kept and removed sits is version specific.
