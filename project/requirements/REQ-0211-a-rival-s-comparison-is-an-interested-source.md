# REQ-0211

Where a claim about one tool is taken from a comparison published by a
competing tool, research MUST check it against the tool it describes before
repeating it.

A comparison page is a primary source about its own tool and an interested,
possibly stale source about every other one; this corpus found one such claim
that the rival's own repository contradicted.
