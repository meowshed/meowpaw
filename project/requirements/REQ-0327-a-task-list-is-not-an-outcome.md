# REQ-0327

**Withdrawn by ADR-2300. Replaced by REQ-3604.**

It read: an epic MUST NOT be reported as realised on the strength of its task list, because a task list is activity and a realised record is an outcome.

ADR-2300 closes an epic when its tasks are done, and REQ-3604 states that rule.
