# REQ-1144

The description of a unit that has to be in context before the model acts MUST
open with a sentence saying what the unit is, and MUST then state in the third
person, with MUST, that the unit is loaded before the work it governs.

On Sonnet 5 the description `meow-prose` shipped, which described the skill
and said when to use it, loaded it in 0 of 30 writing runs, and an obligation
in this form loaded it in 36 of 36. The same obligation addressed to the model
as "you" loaded in 24 of 60 runs, and without the opening sentence in 14 of 30.
