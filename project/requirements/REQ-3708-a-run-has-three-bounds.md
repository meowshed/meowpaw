# REQ-3708

**Withdrawn by ADR-2910. Replaced by REQ-3724.**

It read: a run MUST end when it reaches the iteration ceiling, the time limit or the token budget the person stated in its start command, which requires all three.

It held while a token count could be taken from the transcript as a budget. The only total a hook can make counts each cache read again and begins with the session, not the run, so it ended a run in its first iteration at 24.7 million against a stated 10 million (RES-0351). REQ-3724 keeps the iteration ceiling and the time limit.
