# REQ-0288

**Withdrawn by ADR-2300. Replaced by REQ-3612.**

It read: verification MUST judge whether each check would actually fail if its requirement were violated, and MUST report a check that would not.

ADR-2300 closes a requirement with the tasks that name it and keeps no verification step, evidence file or record review, and REQ-3612 states what holds in its place.
