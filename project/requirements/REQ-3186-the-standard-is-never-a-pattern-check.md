# REQ-3186

The writing standard MUST NOT be enforced by a pattern over the text.

A pattern reads words, and the standard is mostly about shape: a paragraph
opening in bold, an opener announcing how many items follow, a claim written as
a proverb with its reason missing. Reaching those with a pattern means guessing
at meaning, and a check that guesses trips on the wrong text and gets switched
off, taking the rules beside it.

A formatting tool is a different thing and it stays. `prettier` and a Markdown
linter read syntax, and syntax settles nothing the standard is about.
