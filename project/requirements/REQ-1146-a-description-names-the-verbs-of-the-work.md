# REQ-1146

The description of a unit that has to be in context before the model acts MUST
name each verb a request uses for the work it governs, and MUST NOT name work
the unit does not govern.

Sonnet 5 matches the verbs literally: a description saying "written, edited or
reviewed" loaded the writing skill on a rewording request in 1 of 5 runs, and
adding "rewritten" and "reworded" brought it to 6 of 6. Naming "replies",
which the skill does not govern, cut the loads from 22 of 31 to 8 of 20.
