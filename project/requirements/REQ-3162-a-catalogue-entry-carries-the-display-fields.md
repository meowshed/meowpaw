# REQ-3162

A unit's catalogue entry MUST carry the fields the platform displays before an
install: the description, the homepage, the repository, the licence and the
keywords.

For a unit fetched from anywhere but the catalogue's own tree, the platform
shows the entry's fields alone until the unit is installed.
