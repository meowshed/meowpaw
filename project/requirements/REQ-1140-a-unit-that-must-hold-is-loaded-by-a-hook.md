# REQ-1140

A unit that has to be in context before the model acts MUST be loaded by a
mechanism that does not depend on the model choosing to load it, and how often
it is in context when needed MUST be measured.

The model loaded the writing skill in one run of nine where it was needed,
with the skill listed each time. Louder wording is not the fix, because it
makes recent models load units where they are not needed.
