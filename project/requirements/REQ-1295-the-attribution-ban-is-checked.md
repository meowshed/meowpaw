# REQ-1295

The attribution ban MUST be enforced by a mechanical check over the text the
harness produces, run before that text is committed or filed.

The rule fails by being forgotten rather than by being disagreed with, and the
instruction to add attribution usually arrives later in a session than the
rule forbidding it.
