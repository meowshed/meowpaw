# REQ-0519

The unit of work an artifact belongs to MUST be declared in the artifact's own
metadata, and the layout MUST divide by artifact kind rather than by unit of
work.

A directory named for the work that produced an artifact cannot hold a living
document, because the document outlives the work and the folder makes it look
like part of it.
