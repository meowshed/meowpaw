# REQ-0706

**Withdrawn by ADR-2300. Replaced by REQ-3604.**

It read: the harness MUST NOT report an epic as finished while any of its artifacts is in a state verification would report.

ADR-2300 closes a requirement with the tasks that name it and keeps no verification step, evidence file or record review, and REQ-3604 states what holds in its place.
