# REQ-1142

A unit's loadable material MUST be divided into a core that every use of the
unit needs, which names each supporting file and when to read it, and
supporting files that are loaded only for the work that needs them.

Every use pays for the core, so a rule that only one kind of work needs costs
every other kind for nothing. Before the writing skill was divided this way, a
one-line commit message loaded the same 4,800 tokens as a design document.
