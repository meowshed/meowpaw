# REQ-1148

The description of a unit that has to be in context before the model acts MUST
say that the unit MUST NOT be skipped however short or simple the work looks.

The model judges a short text as too small to need a standard, and naming the
kind does not change that judgement: a description naming commit messages
missed the commit request in 3 runs of 3. Adding this sentence took the
description from 21 of 30 writing runs to 31 of 33.
