# REQ-2526

The harness MUST invoke source control in a reading environment with
prompting, paging, advice and machine-wide configuration disabled, and MUST
invoke work that records authorship in the user's own environment.

The second carries their identity and their signing key, and a reading
environment that replaced it would sign commits as nobody.
