# REQ-1382

**Withdrawn. Replaced by REQ-4002.**

It read: the mapping between a task and its work item MUST be recorded on the task
itself rather than in a registry, because a registry outlives the tasks it
maps and an orphan row is indistinguishable from an unprojected task.

Withdrawn by ADR-3090.
