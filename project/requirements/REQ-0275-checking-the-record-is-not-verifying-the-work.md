# REQ-0275

**Withdrawn by ADR-2300.**

It read: the harness MUST distinguish checking the record from verifying the work.

Checking the record asks whether the documents agree with each other and with
the tree; verifying the work asks whether a task's evidence closes what it
claimed.

ADR-2300 removes the verification step, so there is no second act to tell apart from checking the record: a task's gate is its verification.
