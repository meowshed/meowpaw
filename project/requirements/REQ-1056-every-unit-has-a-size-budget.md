# REQ-1056

Each unit of loadable material MUST have a stated size budget.

**Withdrawn by ADR-2970 on 2026-10-11. No replacement.**

It read: each unit of loadable material MUST have a stated size budget.

It left a budget whose only possible outcomes were pass and raise the
ceiling, and the one unit that reached its ceiling had the ceiling raised in
the same change. What loads on every turn is held by the rules on when
material loads, which stay in force.
