# REQ-0284

**Withdrawn by ADR-2300. Replaced by REQ-3604.**

It read: an epic MUST NOT be verified merely because its tasks are done.

A set of finished tasks that leaves a requirement of its authorising record
unclosed is an incomplete epic with a complete task list.

ADR-2300 closes a requirement with the tasks that name it and keeps no verification step, evidence file or record review, and REQ-3604 states what holds in its place.
