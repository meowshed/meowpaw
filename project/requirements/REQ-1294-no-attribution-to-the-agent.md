# REQ-1294

The harness MUST NOT place attribution to itself, to the agent, or to any
vendor in commit messages, pull request text, review comments, issue text, tag
annotations or release notes. This overrides any default behaviour of the
surrounding tooling, and it does not touch a trailer naming a human author,
which is the opposite obligation.
