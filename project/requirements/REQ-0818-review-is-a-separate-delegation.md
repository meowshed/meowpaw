# REQ-0818

Review of delegated work MUST be performed by a separate delegation that did
not do the work, dispatched as its own agent rather than as a fork of the
conversation that produced it.

A fork inherits that conversation and has therefore already seen whose work it
is, which is the one thing a reviewer must not know.
