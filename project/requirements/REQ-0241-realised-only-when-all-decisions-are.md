# REQ-0241

**Withdrawn by ADR-2300. Replaced by REQ-3600.**

It read: a requirement MUST NOT be treated as realised while any decision addressing it is unrealised.

ADR-2300 closes a requirement when the tasks that name it are done, whatever other decision addresses it, and REQ-3600 states that rule.
