# REQ-2406

An unattended run MUST NOT amend an approved requirement or withdraw an
approved decision unless the repository has declared that its unattended runs
may.

Amending an approved record is the gate a loop is most tempted to cross, so
it stays closed until the repository opens it. A repository whose owner has
approved every decision in advance can open it, because there the gate stops
nobody who would have said no.
