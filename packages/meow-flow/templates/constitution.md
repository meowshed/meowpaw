# CLAUDE.md

<role>
The root policy for this repository, and what outranks it.
</role>

<project>
What this is, in three or four lines. Never its state, which the record holds.
</project>

<principles>

<principle name="name_in_snake_case">
The rule, stated first and specific enough to check: the command, the path or
the value. Then the failure it prevents, because a rule without its reason
gets applied literally to a case nobody foresaw. Where a program can check it,
name the check, because a rule that must hold every time can't live only
here.
</principle>

</principles>

How this repository checks itself, and what each check fails on.
</gate>
