<role>
A README is the first page of a project. Its reader decides in one screen
whether to try it, so the working quick start comes before anything else.
</role>

<rules name="sections, in order">
1. Identity: Open with the name and one line on what it is and who it is for.
2. Quick start: Give a quick start that reaches a working result in five steps
   or fewer, and that works when somebody tries it, because a quick start that
   fails loses the reader for good.
3. Install: Then installation, usage with runnable examples, and configuration.
4. Contribute: End with how to contribute and the licence.
</rules>

<rules name="done">
It is done when a new reader gets something working from the quick start alone.
</rules>
