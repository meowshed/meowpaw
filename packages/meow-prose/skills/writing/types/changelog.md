<role>
A changelog is the running record of changes, version by version, read by
somebody looking for when a thing changed.
</role>

<rules name="sections, in order">
1. Version: Head each version with its number and its date as YYYY-MM-DD.
2. Groups: Group entries under Added, Changed, Deprecated, Removed, Fixed and
   Security, so a reader scanning for one kind finds it.
3. Entry: Write one sentence per entry, naming the change, with no marketing
   language.
</rules>

<rules name="done">
It is done when a reader can find the version in which any change landed.
</rules>
