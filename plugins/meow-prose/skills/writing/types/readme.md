<role>
A README is the first page of a project. Its reader decides in one screen
whether to try it, so the working quick start comes before anything else.
</role>

<rules name="sections, in order">
<rule id="identity">Open with the name and one line on what it is and who it is
for.</rule>
<rule id="quick-start">Give a quick start that reaches a working result in five
steps or fewer, and that works when somebody tries it, because a quick start
that fails loses the reader for good.</rule>
<rule id="install">Then installation, usage with runnable examples, and
configuration.</rule>
<rule id="contribute">End with how to contribute and the licence.</rule>
</rules>

<rules name="done">
<rule id="done">It is done when a new reader gets something working from the
quick start alone.</rule>
</rules>
