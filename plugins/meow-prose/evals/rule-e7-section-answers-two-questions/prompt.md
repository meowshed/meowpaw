# Using the CLI

## Installing and upgrading

To install the CLI, download the archive for your platform and put the binary on your path. To upgrade, run `tool upgrade`, which replaces the binary and keeps your configuration. If an upgrade fails, install the previous version again.

## Configuration

The CLI reads `~/.tool/config.toml` at start.
